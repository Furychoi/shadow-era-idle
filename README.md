# 暗影防线 · 八方塔防

静态网页塔防。怪物从八个方位沿道路冲击中央核心，用战斗塔拦路、辅助塔强化与产资源。

## 运行

```bash
./scripts/serve.sh
```

打开 `http://127.0.0.1:8080`。不要用 `file://` 打开。

规则自检：

```bash
node tests/rules.test.js
```

推到 GitHub 后，仓库 Settings → Pages 选 GitHub Actions，即可用 Pages 链接游玩。

## 规则摘要

- 刷新方位：上 / 下 / 左 / 右 / 左上 / 左下 / 右上 / 右下
- 波次越高，普通怪血量和防御越高
- 每波精英；3、7 波小 Boss；5 波 Boss；10 波强力 Boss（会封印 / 弱化战斗塔）
- 战斗塔：近战（小范围 AOE）/ 远程（大范围单体速射）/ 魔法（AOE 或单体特效）
- 辅助塔：Buff（攻速、范围、伤害）与资源（金矿、石场、矿场、伐木场、魔能炉）
- 资源：金币通用；石材主近战升级；矿物主近战与远程；木材主远程与魔法；魔能主魔法

## 操作

点右侧商店选塔，再点草地建造。点已有塔可升级或拆除。N 下一波，空格暂停，1–9 快捷选塔。
