## 3. 世界难度

| ID | 难度 | monsterMult | lootMult | statMult | 等级带 lvMin–lvMax |
|---|---|---|---|---|---|
| **D-01** | 普通 | 1 | 1 | 1 | 1–88 |
| **D-02** | 困难 | 1.5 | 2 | 1.5 | 60–95 |
| **D-03** | 噩梦 | 2.25 | 4 | 2 | 70–100 |
| **D-04** | 地狱 | 3.375 | 8 | 3 | 80–105 |

**D-05 解锁** tier=0 永远开。更高档要求该角色 `diffCleared` 含上一档。

**D-06 图上等级** 底图 `levelMin/Max`（普通带 1–88）线性映射到当前难度带：

```
t = (n - 1) / (88 - 1)
scaled = round(d.lvMin + t * (d.lvMax - d.lvMin))
```

n>88 时：`d.lvMax + (n - 88)`（秘境层）。

**D-07 怪数值** 生成后 hp/伤害/护甲 × `monsterMult`。

**D-08 装备难度戳** 掉落时 `item.diffId = 该角色当前难度`。展示名加「-X难度」。词缀数值 × `statMult`（及强化倍率）。

**D-09 组队人数** 普通按章节：Act1 3–6 … Act5 7–14。困难 8–16、噩梦 9–18、地狱 10–20（覆盖章节表）。

验收：同一张荒芜平原，切困难后怪等级进 60+ 带，掉落名称带「困难难度」。

## 4. 地图与 Boss

进度键：该角色 `campaign.mapKills[mapId]`。清图需求：`isBoss ? bossKills : clearKills`。

**M-01 推进** 同 Act 下一张要求上一张 `mapKills >= need`。跨 Act 要求 `unlockBoss` 已击杀。

**M-02 自动下一图** `autoNextMap` 默认开。清完且未卡章节 Boss/裂隙守卫时切下一张已解锁图；可进下一档已解锁难度。

**M-03 章节 Boss 出场**

- 未击杀过且进度就绪：概率 **100%**。
- 已击杀：`min(1, 0.1 + pity×0.05)`。未出则 pity+1。

**M-04 章节 Boss 数值锁定**

- 伤害相对同级模板 **×10**（`CHAPTER_BOSS_DMG_MULT`）
- 普攻间隔与技能 CD **÷5**（`BOSS_SPEED_MULT`）

**M-05 死亡** 出战角色倒下：`respawnTimer = 8` 秒。战场/营地/角色页显示倒计时。复活满血。8 秒内不刷下一波。

**M-06 可见范围** 怪物 iso 必须夹在画布内：左右 pad **36px**，上 **56px**，下 **28px**。用与绘制相同的 cover 布局换算，**禁止**夹完屏坐标后再用网格轴夹回去（会把怪挤出画面）。出生、AI（含逃跑/嘲讽/风筝）、绘制各钉一次。

地图与 Boss 名录见 PRODUCT.md §5。数据源 `js/data.js` 的 `MAPS` / `BOSSES`。

**M-07 小秘境** 该角色击杀迪亚波罗后开。层需求击杀 `70 + (floor-1)×2`。满层出裂隙守卫（巴尔模板 × 层数倍率）。击杀：层+1，进度清零。怪强度 `1 + (floor-1) × kindRate`（普通 0.02，精英 0.03，稀有/隐藏 0.04，Boss 0.05）。

**M-08 挂机暂停** 挂机角色若停在「未击杀的就绪章节 Boss」或「裂隙守卫就绪」，**停止**后台击杀（避免后台秒 Boss）。

验收：普通墓穴第一次必出薇斯娜；死后 8 秒复活且有「已倒下」；嚎叫逃跑的怪不离开画布。

## 5. 怪物生成（出战）

清图系数 `clearFactor = mapKills / clearKills`（秘境 `0.9 + (floor-1)×0.02`）。

**N-01 类型权重** `rollKind(f)`：

```
hiddenP = f<0.75 ? 0 : min(0.11, (f-0.75)×0.045)
rareP   = 0.09 + min(0.20, f×0.065)
eliteP  = 0.16 + min(0.24, f×0.07)
其余普通
```

**N-02 类型倍率** hp/伤害/经验：普通 1/1/1；精英 2.5/1.5/3；稀有 6/2.2/8；隐藏 8.5/2.5/14；哥布林 2.2/0.35/6。

**N-03 哥布林** 每波额外尝试，概率 `(0.01 + min(0.07, f×0.022)) × DROP_RATE`。

**N-04 技能包** 哥布林无技能。特殊怪：

| 类型 | 伤害技能数 | 诅咒技能数 |
|---|---|---|
| 精英 / 稀有 | 1 | 0 |
| 隐藏 | 2 | 0 |
| 稀有 Boss | 2 | 1 |
| Boss / 章节 / 裂隙 | 2 | 2 |

伤害池：元素师火冰电（不含静电立场、九头蛇、能量护盾）+ 狂战士战斗/嚎叫/战吼 + 死灵毒骨。诅咒池：死灵五咒。怪物技能伤害系数 `MONSTER_SKILL_DMG = 0.42`。技能 CD 对 Boss 再 /5。

**N-05 种族抗性** 用 `RACES` 表（亡灵毒抗等）。不要给隐藏/Boss 另开一套抗性除非数据表有。

验收：后期图能刷出隐藏；Boss 日志出现技能名；元素师怪不会放静电立场。

## 6. 技能（英雄）

每职业 3 树 × 5 技能，默认 `maxLevel=10`。出生 `skillPoints=2`，默认栏 1 个起手技。升级 +1 点，级上限 **99**。

**S-01 学习** 要有点、未满级、前置技能 ≥1、角色等级 ≥ `reqLevel`。另扣资源 `skillLearnCost`：

```
gold = floor(16 × next² × (0.5 + req×0.055) × (解锁?1.65:1))
next≥2 金属，≥3 布，≥4 晶；高等级额外加材料
```

**S-02 联动** `synergyMult = 1 + min(Σ(投入点数×pct/100), 2.8)`。`+技能等级` 不进联动。

**S-03 标签共鸣** 已学（等级≥1）同标签数量：≥4 / ≥6 / ≥8 → +6% / +12% / +22% 伤（投射、近战、火、冰、电、毒分别累加）。投射≥6 穿透+1；AOE≥6 范围+15%；召唤≥6 召唤+30%。

**S-04 圣骑光环** `auraSlot` 进攻/防守各择一，点亮新光环时关掉同槽其它。

**S-05 性态** 仅暗金/传奇/远古。`MORPHS` 表。对技能生效时：武器 > 防具 > 首饰；同一 `skillId` 只取一条。职业不匹配不生效。

**S-06 武器门** 弓树要弓/弩；标枪树要标枪。不满足则该技能不进循环。

验收：狂战士旋风伤害随跃击点数涨且不超过 +280% 联动；圣骑不能同时开两个进攻光环。

## 7. 掉落（出战）

全局 `DROP_RATE = 0.75`。

**L-10 件数** `dropRolls(expected)`：`e = expected × 0.75`，件数为 `floor(e)` 再以小数部分为概率 +1。

| 类型 | expected |
|---|---|
| 普通 | 0.10 |
| 精英 | 1.18 |
| 稀有 / 稀有 Boss | 1.55 |
| 隐藏 | 2.50 |
| Boss / 裂隙守卫 | 2.00 |
| 哥布林 | `lootRolls` 默认 5（至少 1 件） |

**L-11 品质权重**（再乘类型 kindBonus 于高品质）

| 品质 | 基础权重 | kindBonus 乘在哪些品质 |
|---|---|---|
| 普通 68.96 / 魔法 24 / 稀有 6.5 | — | 不乘 |
| 套装 0.43 / 暗金 0.088 / 传奇 0.132 / 远古 0.025 / 远古套 0.018 / 远古暗金 0.014 | 高品质 | 哥布林 5.4、隐藏 4.8、稀有 4.2、精英 2.6、Boss 3.8、普通 1 |

**L-12 底材** 随机部位。64% 优先本职 `reqClass` 或本职武器类型（元素师副手法珠）。其余无职业限制底材。

**L-13 装等** `itemLevel = clamp(怪等级)`，`reqLevel = clamp(ilvl-4, 1, 110)`。

**L-14 拾取** `addLoot(state, item)` 默认出战角色。自动出售命中则卖或分解（分解 **金=0**）。背包满折金。

**L-15 地面** 掉落在等距地面，英雄走近拾取。有掉落时不刷下一波。

验收：普通小怪多数空箱；稀有明显更高件数/品质；分解日志无「+金」。

## 8. 挂机与离线

**H-01 谁挂机** 在线：`charId ≠ activeCharId`。死亡中只扣复活时间。

**H-02 击杀间隔** 与出战同口径：`(怪HP×难度×秘境) / DPS + 0.4 + 1.15/平均波次人数` 秒，下限 0.2。

**H-03 每击杀** 用 `createMonster` / 哥布林同一生成（含精英/稀有/隐藏）。经验 `monster.exp`，金币 `monsterKillGold`，掉落 `rollMonsterItems`（与出战 `spawnDrops` 同一期望件数与品质池）。进**该角色**背包，走**该角色**自动出售。

**H-04 出装** 与出战相同：普通 expected 0.10，精英 1.18，稀有 1.55，隐藏 2.5，哥布林 `lootRolls`；再乘 `DROP_RATE`。

**H-05 离线** 时长 `min(经过小时, 12)`。效率：≤2h=1；≤8h 按 2h×1 + 其余×0.7 平均；>8h 再叠加 ×0.4。对克隆档 `tickIdleHeroes(..., includeActive:true)`，领取时对真档再跑同一 `dt`。

挂机仍不后台结算未打的章节 Boss / 已就绪的裂隙守卫（H-08 / M-08）。

验收：切到第二职业，其背包会慢慢出现装备/金；出战角色背包不同步增加这些件。离线弹窗可领取，金经验与击杀数为正。

## 9. 背包与处理

**B-01 容量** `24 + bagExpands×8`，最多扩 24 次。

**B-02 自动出售** 按角色。关 / 出售 / 分解。品质阈值用 `AUTO_SELL_MODES`。`minKeepLevel>0` 则 ilvl≥该值不处理。`keepBetter`：试穿后 DPS 提升 **>2%** 则保留。

**B-03 出售金**

```
gold = (20 + ilvl×18 + ilvl²×0.32) × qMult × (1+词缀×0.12) × (1+强化×0.08)
     × (0.7 + 0.3×lootMult) × (专属词?1.22:1) × (传奇特效?1.15:1)
floor，至少 10
```

qMult：白 1、蓝 1.9、黄 3.5、套 5.4、暗金 6.6、传奇 8.8、远古约 12.2–12.6。

**B-04 分解** `gold=0`。

```
rank = Q_RANK+1
base = round((rank×1.1 + ilvl/10) × (1+词缀×0.06)) 至少 1
武器副手 → 金属=base，晶=floor(base×0.08)+(rank≥4?1:0)
首饰 → 晶=base
防具 → 金属=max(1, round(base×0.2))（base=1 则金属 1），布=其余
```

Q_RANK：白0 蓝1 黄2 套3 暗金4 传奇5 远古系6。

**B-05 强化** 白/蓝不可强化。黄上限 30% 词缀/基础，套/暗金/传奇 50%，远古 75%。强化 0–10 线性吃满该 cap。费用：武器扣金属、首饰扣晶、防具扣布 + 金（`enhanceCost`）。

**B-06 评分** 单件 atk+surv；人物战力 `combatPowerScore(DPS, EHP)`。地图按钮用推荐战力对比提示。

**B-07 「留更高 DPS」** 用 `compareDPS` 试穿对应部位（狂战士武器可试副手双持）。

验收：分解只加材料；自动分解不加工资；扩容格子数 +8。

## 10. 据点

## 11. 经验与升级

**E-01 升级经验** `expForLevel(n)`：

```
e = 95n + 26n²
n≥20 再 × (1+(n-19)×0.05)
n≥40 再 × (1+(n-39)×0.085)
n≥60 再 × (1+min(n-59,15)×0.08)
n≥75 再 × (1+(n-74)×0.035)
n≥90 再 × (1+(n-89)×0.05)
floor；n 夹在 1–110
```

升级：`exp -= 需求`，`level++`，`skillPoints++`，满血。

**E-02 等级差惩罚** 函数 `expLevelInfo` **现行恒为 mult=1**。不要按旧文案做衰减，除非单独立项改 E-02。

**E-03 挂机经验** 用 H-03 的 raw，再乘 E-02。

验收：1→2 所需经验等于 `expForLevel(1)`。
