# 暗影纪元：放置编年史 — 产品说明

> 玩家向摘要。改数值与规则请改 **[可执行策划文档 GDD](GDD.md)**（含规则 ID、公式、验收）。  
> 以当前可玩版本为准（静态页，资源缓存 `v=154`）。日期：2026-08-26

## 1. 产品是什么

**暗影纪元：放置编年史**是一款浏览器单机放置 RPG。玩家管选图、加点、换装、出售规则；系统管寻敌、技能循环、掉落与离线结算。

对标暗黑破坏神 2 的物品、职业与章节骨架，做成 **45° 等距像素自动战斗**。无账号、无后端，进度存在本机浏览器。

| 项 | 说明 |
|---|---|
| 形态 | 静态 HTML/CSS/JS，可 GitHub Pages 托管 |
| 存档 | `localStorage` 键 `shadow-era-save-v11` |
| 公网 | https://furychoi.github.io/shadow-era-idle/ |
| 本机 | `./scripts/serve.sh` 或任意静态服务（勿用 `file://`） |

玩家要做的循环：**出征刷图 → 掉装备 → 换装/出售/分解 → 强化 Build → 打更高难度与章节 Boss → 多角色同时挂机**。

## 2. 界面与操作

桌面三栏；窄屏为底栏三页（战场 / 营地 / 地图）。

**左 · 营地（当前出战角色）**  
人形部位换装、生命/资源/经验、背包（筛选、分页、多选、整理、出售、分解）、自动出售规则、扩容。点「技能」打开加点与挂机技能栏。左上「据点」在解锁后打开城镇（战斗不暂停）。

**中 · 战场**  
等距画布（战斗区锁定 480px 宽）、怪血与击杀进度、技能图标叠在地图上、死亡倒计时、角色切换条、战斗日志与掉落日志（高度与营地出售/分解工具条对齐）。

**右 · 效率与地图**  
属性分页、离线收益、世界难度、章节地图列表（过长可滚）、自动下一图。

角色切换只换**出战**角色。未出战的已解锁角色显示「挂机」，继续在各自地图后台击杀。

## 3. 角色

开局仅 **狂战士**。其余职业按**该角色自己的战役进度**解锁（普通/困难通关对应章节 Boss）：

| 职业 | 解锁 | 主属性 | 资源 | 定位 |
|---|---|---|---|---|
| 狂战士 | 开局 | 力量 | 怒气（击中/击杀回复） | 近战物理、旋风、战吼 |
| 元素师 | 普通 · 通关第一章（毒后·薇斯娜） | 智力 | 魔法 | 火/冰/电法术 |
| 圣骑士 | 普通 · 通关第三章（议会三魔） | 力量 | 魔法 | 光环 + 战斗技能 |
| 死灵法师 | 普通 · 通关第五章（巴尔） | 智力 | 魔法 | 召唤、毒骨、诅咒 |
| 亚马逊 | 困难 · 通关第一章 | 敏捷 | 魔法 | 弓弩 / 标枪 |
| 暗影刺客 | 困难 · 通关第三章 | 敏捷 | 能量 | 陷阱、武学、影子 |
| 德鲁伊 | 困难 · 通关第五章 | 智力 | 魔法 | 元素、变形、召唤 |

每个角色独立：等级、技能、装备、背包、金币、材料、药水、自动出售、地图进度、世界难度。仓库是据点共享。

---

## 4. 战斗（出战角色）

- 英雄自动贴近或保持射程，按挂机栏优先级放技能，空档普攻。
- 怪物种族有抗性（亡灵、恶魔、野兽、人型、昆虫、构造体、元素）。
- 类型：普通、精英（蓝词缀）、稀有、隐藏、宝藏哥布林、巡游 Boss、稀有 Boss、章节 Boss、裂隙守卫。
- 章节 Boss **伤害 ×10**、**攻速/技能冷却 ×5**（相对同级模板）。
- 怪物技能：稀有 1 个伤害技能；隐藏 2 个；Boss 2 个伤害 + 2 个死灵诅咒（稀有 Boss 1 个诅咒）。元素师怪不用静电立场/九头蛇/能量护盾等。
- 英雄可被诅咒（减益条显示在战场 HUD）。
- 死亡：战场「已倒下」+ 秒数；营地与角色页同步。**8 秒**后原地满血复活。倒计时期间不刷下一波。
- 怪物坐标夹在**可见画布内**（cover 缩放后菱形角在屏外，逃跑/风筝/哥布林不会跑出画面）。

药水：生命过低自动喝红（Boss 阈值更高）；商会/药房可买并设自动补给。

## 5. 地图与进度

五章线性图 + 通关迪亚波罗后的 **小秘境**。每张图有清图击杀数；Boss 图用 `bossKills`。进度按**角色战役**分别计算。

世界难度（每角色自选，需该角色通关前一档）：

| 难度 | 怪倍率 | 掉落倍率 | 装备属性倍率 | 等级带 |
|---|---|---|---|---|
| 普通 | 1 | 1 | 1 | 1–88 |
| 困难 | 1.5 | 2 | 1.5 | 60–95 |
| 噩梦 | 2.25 | 4 | 2 | 70–100 |
| 地狱 | 3.375 | 8 | 3 | 80–105 |

图上显示的怪物等级 = 底图等级映射到当前难度带。组队人数（一波怪数量）随章节与难度升高。

**自动下一图**：清完当前图且未勾住 Boss 时，推进下一张已解锁图；也可进下一档难度。

### 章节与 Boss

| 章 | 地图（顺序） | 章节 Boss |
|---|---|---|
| 一 | 荒芜平原 → 血沼 → 霜寒荒野 → 寒冰洞窟 → 碎石高地 → 黑森林 → 古老神殿 → 幽暗墓穴 | 毒后·薇斯娜 |
| 二 | 干裂沙丘 → 鲁高因下水道 → 沙漠王宫 → 失落古墓 | 沙虫王·杜瑞尔 |
| 三 | 丛林小径 → 蜘蛛森林 → 剥皮魔巢穴 → 库拉斯特码头 → 崔凡克议会 | 议会三魔 |
| 四 | 外围炼狱 → 天谴之城 → 火焰之河 → 混沌避难所 | 迪亚波罗 |
| 五 | 冰冻高地 → 先祖之路 → 世界之石要塞 | 巴尔 |

Boss 图需先攒够击杀再出 Boss。已击杀过的章节 Boss 可按概率再次出现（含保底）。

**小秘境**：通关迪亚波罗后开放。层数越高怪越强。清层进度满后出裂隙守卫；击杀升层并有独立掉落（含远古机会）。

挂机角色停在「未打的章节 Boss」或「裂隙守卫已就绪」时**暂停刷怪**，避免后台秒 Boss。

## 6. 技能

每职业 **3 棵树 × 5 技能 = 15 个**（主动 / 光环 / 被动）。主动默认满级 10。同树有前置。1 级 1 点。

强度三层（装备性态只改释放形态，不改点数公式）：

1. **点数联动**：主技能伤害享受协同技能投入点数加成（`+技能等级`不进联动）。
2. **标签共鸣**：同标签学得足够多时给数值或形态（投射、近战、AOE 等）。
3. **起手 / 收招窗口**：带 opener / window / finisher 标签的技能按连招窗口加成。

挂机栏只放玩家勾选的技能；光环类进栏后持续生效。弓技能要弓/弩，标枪技能要标枪。

暗金 / 传奇 / 远古可带 **技能性态**（穿刺、分裂、新星化、连锁、轨迹残留、元素转化、击中施放、收招重置、人兽施法、窗口延长）。同一技能最多一条性态，武器优先于防具优先于首饰。

## 7. 装备与掉落

部位：武器、头盔、胸甲、手套、靴子、腰带、项链、左戒、右戒、副手。

品质（颜色与词缀条数）：

| 品质 | 词缀条数 |
|---|---|
| 普通 / 魔法 / 稀有 | 0 / 1–2 / 3–6 |
| 套装 / 暗金 / 传奇 | 3–5 / 5–6 / 4–5 |
| 远古传奇 / 远古套装 / 远古暗金 | 5 / 5 / 6 |

普通怪品质权重以白蓝为主，黄绿暗金橙与远古极低。精英 / 稀有 / 隐藏 / Boss / 哥布林提高高品质权重。

物品带 **掉落时的世界难度戳**（名称后缀如「-噩梦难度」），属性吃该档 `statMult`。约 64% 底材偏向掉落角色的职业/武器类型。

评分：攻击分与生存分，用于对比、整理、自动出售「留更高 DPS」。

**出战掉落（地图上可见）**

全局掉率系数 `DROP_RATE = 0.75`。每只怪期望件数约：普通 0.1、精英 1.18、稀有/稀有 Boss 1.55、隐藏 2.5、Boss/裂隙守卫 2；再乘 0.75。哥布林多袋金币 + 多件装备。拾取时走该角色自动出售/分解；背包满则折金。

**挂机角色掉落（后台，无地面）**

与出战同一套怪生成、金币、件数和品质池（含精英/稀有/隐藏/哥布林）。装备进**该角色背包**，走该角色自动出售。切到该角色才能在营地看到。未打的章节 Boss / 已就绪裂隙守卫仍暂停后台击杀。

**离线**

离开最多按 **12 小时**结算，效率阶梯：0–2h 100%，2–8h 70%，8–12h 40%。对**所有角色**（含当时出战）走挂机击杀，不是战场模拟。领取时再套用各角色自动出售。

## 8. 背包、出售、分解、强化

- 初始 24 格，每次扩容 +8，最多扩 24 次。
- 锁定、品质筛选、分页、多选、一键整理（稀有度 / 装等 / 评分）。
- **自动出售按角色保存**，与地图进度分开。可选出售或分解；可设「装等 ≥ N 不处理」「留更高 DPS」。
- **分解**：出金属 / 布 / 晶，**不出金币**。武器副手偏金属，首饰偏晶，防具偏布。
- **出售**：按装等、品质、词缀、强化、难度倍率折金。
- 铁匠：强化（黄及以上，品质决定强化上限）、洗练；材料来自分解。

## 9. 据点

肃清 **血沼** 后解锁「荒村据点」。进入据点**不暂停**出征。

| 建筑 | 作用 |
|---|---|
| 议事厅 | 升级，解锁训练场等级上限 |
| 仓库 | 跨职业存货（基础 32 格） |
| 铁匠铺 | 强化 / 洗练 / 分解 |
| 商会 | 补给 |
| 训练场 | 永久属性（受议事厅等级限制） |
| 药房 | 药水与自动补给 |
| 神龛 | 占位，未开放 |

## 10. 战斗外数值（给策划对照）

- 挂机击杀间隔：与出战相同口径（怪 HP / DPS + 走位余量 + 波次间隔分摊）。死亡时只倒计时复活，不击杀。
- 挂机每击杀：用出战同一只怪的经验、金币与掉落表，地图进度 +1（未满清图需求时）。
- 经验有等级差衰减（打过低级图效率差）。

## 11. 已知产品差异（对 README / 早期 GDD）

以下以**本文件 + 代码**为准：

- 开局只有狂战士，不是狂战士/亚马逊二选一。
- 亚马逊 / 刺客 / 德鲁伊走困难章节解锁，不是杜瑞尔一次给两个职业、迪亚波罗给死灵。
- 每职业 15 技能，不是早期 Demo 的 12。
- 挂机出装与出战同一掉落表；背包仍按角色分开。
- 分解无金币。
- 布局：战斗地图宽度、技能叠图、日志对齐出售栏，已作为界面锁定，改动需产品明确点头。
